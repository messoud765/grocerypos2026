# تطبيق نقطة البيع (POS) - محل المواد الغذائية

تطبيق Flutter جاهز لتسيير محل بيع المواد الغذائية: البيع، المخزون، المستخدمين، والتقارير.

## المميزات

- شاشة البيع (Cashier): بحث سريع، إضافة للسلة، دفع نقدا أو بالكارط، فاتورة فورية.
- تسيير المنتوجات: إضافة / تعديل / حذف، تنبيه عند نقص المخزون.
- حسابات متعددة: مدير (Admin) وكاشير (Cashier).
- التقارير: مبيعات اليوم، الأسبوع، الشهر.
- قاعدة بيانات محلية (SQLite): يخدم بلا Internet.
- سكان الباركود: تسكان منتوج فالبيع باش يتزاد للسلة مباشرة.

## حساب المدير الافتراضي
- اسم المستخدم: admin
- كلمة السر: admin123
